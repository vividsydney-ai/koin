# Session 2026-07-06 — Fix 404 on koin-web-koinaku deployment

## Work done
- Diagnosed why `https://koin-web-koinaku.vercel.app/` returned 404.
- Root cause: Vercel project was created with framework preset "Other" and default output directory, so it didn't serve the Next.js static export from `out/`.
- Added `vercel.json`:
  - `framework: null`
  - `buildCommand: "next build"`
  - `outputDirectory: "out"`
  - `installCommand: "pnpm install"`
- Removed redundant `distDir: "out"` from `next.config.ts` (Next.js static export already uses `out/` by default).
- Re-deployed and verified the alias URL returns HTTP 200.
